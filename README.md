# Regatta — Android builds

Tactical sailing app for club racing: start timer and line bias, next mark, laylines, wind shifts, course from a file
or typed in as announced, wind forecast. Works with the boat instruments through a Signal K gateway or with the phone
alone (GPS plus manual / forecast / tack-estimated wind).

**Download the latest Android build:**
https://github.com/ikmedia/regatta-releases/releases/latest/download/regatta.apk

Install: open the link on the phone, tap the downloaded `regatta.apk`, allow installing apps from the browser when
asked, confirm. On first start allow Location "while using the app". New versions install over the old one.

This repository holds only the builds; the source lives in a private repository.
